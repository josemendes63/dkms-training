# Kubectl Cheatsheet

## Cluster

```bash
kubectl cluster-info
kubectl get nodes
```

## Pods

```bash
kubectl get pods
kubectl describe pod POD
kubectl logs POD
```

## Deployments

```bash
kubectl get deployments
kubectl scale deployment nginx --replicas=3
```

## Services

```bash
kubectl get svc
```

## Ingress

```bash
kubectl get ingress
```

## ConfigMaps

```bash
kubectl get configmaps
```

## Secrets

```bash
kubectl get secrets
```
